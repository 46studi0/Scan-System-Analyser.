Привет.
Мой проект создан исключительно в образовательных и развлекательных целях. Спасибо за прочтение <3
Пожалуйста, используйте только свой интернет.

Требования:
python 3
scapy - 2.5.0
pandas - 2.0.0 (если хотите)
numpy - 1.24.0
scikit-learn - 1.3.0

В Linux требуется `libpcap` (обычно он уже установлен). В macOS используйте `brew install libpcap`. В Windows используйте Npcap (https://npcap.com/).

Итак, начнём.

1) Скачайте Python 3 и NCAP. Также скачайте все файлы моего проекта и поместите их в одну папку (например, C:\SCANNER\).

2) Откройте PowerShell в этой папке (нажмите Shift + щелкните правой кнопкой мыши в проводнике файлов → «Открыть окно PowerShell здесь»), затем выполните команду: python -m venv venv, затем venv\Scripts\Activate.ps1 (если возникнет ошибка, связанная с политикой выполнения скриптов, выполните еще раз: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass) и, наконец, pip install -r requirements.txt.

3) Закройте и запустите PowerShell от имени администратора. Найдите PowerShell в меню «Пуск», щелкните правой кнопкой мыши → «Запустить от имени администратора», вернитесь в папку проекта `cd C:\netsentry` и повторно активируйте виртуальное окружение `venv\Scripts\Activate.ps1`.

4) Выполните команду `ls` и убедитесь, что видите `main.py` и другие файлы.

5) Настройте зависимости. Выполните команду `pip install -r requirements.txt` — убедитесь, что вы делаете это в конкретном окне, где в командной строке отображается `(venv)`, и что окно запущено от имени администратора.

6) Узнайте имя вашей подсети и интерфейса. Выполните команду `ipconfig` и найдите строку «IPv4 Address» (например, 146.111.1.11) и маску подсети.

7) Запустите сканирование. "python main.py scan --network 146.111.1.11 --output scan_results.json" - замените подсеть на ту, что была указана на предыдущем шаге. Если Scapy не обнаружит интерфейс автоматически, может потребоваться перезагрузка после установки Npcap.

8) ВЫ УВИДИТЕ КОЛИЧЕСТВО УСТРОЙСТВ И ИХ IP-АДРЕСА.

9) Получите список интерфейсов. Запустите `python -c "from scapy.all import show_interfaces; show_interfaces()"` - это отобразит таблицу всех сетевых интерфейсов, которые Scapy обнаруживает через Npcap.

10) Найдите в таблице строку, где в столбце IP отображается (например) 146.111.1.11 (это ваш адаптер Ethernet 4 из ipconfig). Скопируйте значение из столбца Name или Description для этой строки — это значение, которое необходимо передать параметру --iface.

11) ЗАПУСТИТЕ команду `python -c "from scapy.arch.windows import get_windows_if_list; [print(repr(i['name'])) for i in get_windows_if_list() if i['ips'] and '192.168.1.12' in i['ips']]` И ПОСМОТРИТЕ НАЗВАНИЕ ВАШЕГО АДАПТЕРА (например, Ethernet 4).

12) Запустите захват. `python main.py capture --iface "Ethernet 4" --duration 30 --pcap-out capture.pcap --csv-out capture.csv` Вместо Ethernet 4 используйте имя из предыдущего шага. Имя должно быть заключено в кавычки. ПОДОЖДИТЕ 30 СЕКУНД (ВЫ МОЖЕТЕ ИЗМЕНИТЬ ПРОДОЛЖИТЕЛЬНОСТЬ, ИЗМЕНИВ ПАРАМЕТР --duration 40\50\60...).

13) Теперь запустим анализ аномалий. python main.py analyze --csv capture.csv --output report.json Теперь вы видите все аномалии. Если вы не понимаете, можете скопировать этот результат в AI, и он поможет вам разобраться :)

14) Проверьте, кто эти IP-адреса: python main.py analyze --csv capture2.csv --output report2.json

15) Кто подключался недавно. python main.py scan --network (например) 146.111.1.11 --db netsentry.db Просмотреть накопленную историю: python main.py history --db netsentry.db

16) Кто появился впервые за последние 24 часа. python main.py history --db netsentry.db --new-since-hours 24

17) Определите ТИП УСТРОЙСТВА: установите новую зависимость. pip install manuf

18) Запустите сканирование снова: python main.py scan --network 192.168.1.0/24 --db netsentry.db
